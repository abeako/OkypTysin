# Дәлел · Aura monsters · Órleu Hack 2026

Репозиторий команды «Aura monsters» на хакатоне Órleu Hack 2026 (hackathon.kz).
Трек: функциональная грамотность школьников 7–9 классов, в том числе в сельских школах.

> ChatGPT решает за ученика. «Дәлел» заставляет ученика решить самому — и доказать, откуда он это взял.

## О проекте

**Проблема.** PISA-2025: чтение в Казахстане — 385 баллов и не сдвигается 16 лет; базового уровня по чтению достигают только 36% 15-летних. При этом 38% школьников просят чат-бота пересказать текст, который должны прочитать сами. Большинство «ИИ-репетиторов» решают и пересказывают за ученика — и усиливают проблему.

**Решение.** «Дәлел» (каз. «доказательство») — веб-приложение (PWA), в котором ИИ доводит ученика до ответа, но **никогда не даёт ответ**:

1. **Задача разобрана на шаги** (по процессам PISA): что спрашивают → докажи (выдели в тексте) → действие или вывод → ответ.
2. **Доказательство касанием:** ученик касается в тексте чисел или предложения, на которых держится ответ. Без верного доказательства дальше не пройти. В условиях есть лишние данные-ловушки.
3. **Лестница подсказок:** наводящий вопрос → направление → задача-близнец с полным решением на других числах.
4. **Ответ проверяет код, а не ИИ.** Каждая подсказка ИИ проходит фильтр утечки ответа (на сервере и ещё раз на телефоне).

Работает **без интернета** (банк задач и подсказок кэшируется), на **казахском и русском**, на дешёвом телефоне (приложение — 73 КБ в сжатом виде).

**Что уже работает:**
- 12 задач (6 математика + 6 чтение) на kk и ru, контексты из жизни Казахстана: автобус в Баянаул, счёт за свет, рассрочка, сено на зиму, объявление акимата, мошенническое SMS, сайгаки и др.
- Пошаговое решение, выделение касанием, проверка доказательства и ответа кодом.
- Подсказки уровней 1–2 и задача-близнец (уровень 3) — офлайн; при наличии сети ИИ (Claude) переформулирует подсказку под ошибку ученика.
- Фильтр утечки: ловит ответ во всех записях (`11:30`, `11.30`, `11 ч 30 мин`, «половина двенадцатого», `5 500`, «5,5 тыс.»), номер правильного варианта, дословную цитату предложения-доказательства. После 2 неудач — заранее записанная подсказка.
- Офлайн-режим после первого открытия (service worker), переключатель ҚАЗ/РУС, счётчик ошибок по шагам.

Подробно: [`docs/concept.md`](docs/concept.md).

> ⚠️ Казахские тексты задач написаны без носителя языка — **их должен проверить носитель из команды** (файлы `src/tasks/*.ts`, блоки `kk`).

## Стек

- React 18 + TypeScript + Vite 6
- PWA: `vite-plugin-pwa` (Workbox), офлайн-кэш интерфейса и банка задач
- Серверная функция `/api/hint` (Vercel) → Claude API (`@anthropic-ai/sdk`, модель `claude-opus-5-5`, `effort: low`)
- Тесты: Vitest (180 тестов), сквозной сценарий — Playwright

## Как запустить

```bash
git clone https://github.com/hackathon-kz/orleu-hack-2026-224-aura-monsters.git
cd orleu-hack-2026-224-aura-monsters
cp .env.example .env    # впишите ANTHROPIC_API_KEY (без ключа работают офлайн-подсказки)
npm install
npm run dev             # http://localhost:5173
```

Проверки:

```bash
npm test              # все тесты: логика, фильтр утечки, /api/hint, банк задач
npm run check-tasks   # только банк задач: пересчёт ответов кодом, отсутствие утечек в подсказках
npm run build         # сборка в dist/
npm run e2e           # сценарий демо в браузере (нужен Playwright, сначала npm run build)
```

## Деплой (Vercel, можно с планшета)

1. Зайдите на vercel.com → **Add New → Project** → импортируйте этот репозиторий с GitHub.
2. Framework: **Vite** (определится сам). Ничего не меняйте.
3. **Environment Variables:** добавьте `ANTHROPIC_API_KEY` = ваш ключ Claude API.
4. **Deploy.** Папка `api/` автоматически станет серверной функцией `/api/hint`.

Если у Vercel нет доступа к организации `hackathon-kz`, сделайте форк репозитория в свой аккаунт и импортируйте форк.

## Переменные окружения

| Переменная | Где | Зачем |
|---|---|---|
| `ANTHROPIC_API_KEY` | только сервер | подсказки ИИ; без него — офлайн-подсказки |
| `HINT_MODEL` | только сервер, необязательно | модель для подсказок (по умолчанию `claude-opus-5-5`) |

Сам `.env` в репозиторий не кладём: он в `.gitignore`. Ключ никогда не попадает в браузер.

## Структура проекта

```
src/
  tasks/            банк задач: 12 файлов, в каждом версии kk и ru + solve() для пересчёта ответа
  lib/check.ts      проверка ответа (число, время, выбор) и доказательства
  lib/leak.ts       фильтр утечки ответа
  lib/segments.ts   разбиение текста на фрагменты для выделения касанием
  components/TaskPlayer.tsx   экран задачи: шаги, выделение, подсказки
  App.tsx, i18n.ts  список задач, переключатель ҚАЗ/РУС, тексты интерфейса
server/
  hint.ts           логика /api/hint: проверка запроса → ИИ → фильтр → повтор → офлайн-подсказка
  prompt.ts         системный промпт репетитора
  claude.ts         вызов Claude API
api/hint.ts         серверная функция Vercel
tests/              тесты (Vitest)
e2e/demo.cjs        сценарий демо в браузере
docs/concept.md     полный бриф: проблема, решение, питч, Q&A
```
